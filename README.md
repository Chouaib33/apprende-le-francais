# 🇫🇷 تعلّم الفرنسية — Apprendre le français

منصة ويب متكاملة لتعليم اللغة الفرنسية للناطقين بالعربية، موجّهة خصوصاً لطالب جامعي يريد الارتقاء بمستواه من الصفر (A1) حتى المستوى المتقدّم الجامعي (B2)، وفق الإطار الأوروبي المرجعي المشترك للغات (CECRL).

## ✨ المزايا الرئيسية

### المستويات والمحتوى (CECRL)
- **A1** مبتدئ: التعارف، الأرقام، الأسرة، الوقت، الأفعال `être`/`avoir`/المجموعة الأولى، أدوات التعريف، النفي.
- **A2** مبتدئ متقدم: `Passé composé` و`Imparfait`، الوصف، التسوق، السفر، الاتجاهات، المقارنة.
- **B1** متوسط: المستقبل، الشرط، الضمائر المتصلة، التعبير عن الرأي، فقرات مترابطة، مواضيع اجتماعية.
- **B2** متوسط متقدم: **توجيه جامعي** — الشرط الماضي، الجملة الشرطية بأنواعها، الحجاج، النصوص الصحفية/الأكاديمية، التلخيص، العرض الشفوي، المقال الحجاجي.

كل مستوى مقسّم إلى وحدات، وكل وحدة إلى دروس صغيرة (15–20 دقيقة). كل وحدة تنتهي **بمهمة واقعية** (المقاربة actionnelle) وكل مستوى ينتهي **باختبار خروج** يمنع الانتقال للمستوى التالي قبل النجاح.

### المهارات الأربع
- **الاستماع**: تسجيلات صوتية (TTS) بلهجات مختلفة (فرنسا، بلجيكا، كيبيك، المغرب العربي) مع نسخ نصية قابلة للإظهار/الإخفاء.
- **القراءة**: نصوص متدرجة مع مساعدات مفردات وأسئلة فهم.
- **التحدث**: تسجيل صوت عبر Web Speech API مع **تقييم آلي للنطق** (درجة + كلمات مفقودة).
- **الكتابة**: تمارين كتابة حرة مع **تصحيح آلي وتغذية راجعة مفصّلة** تشرح القاعدة (وليس صح/خطأ فقط).

### البيداغوجيا
- مقاربة تواصلية + تعلّم بالمهام (مهام واقعية في كل وحدة).
- **التكرار المتباعد (SRS)**: بطاقات ذكية بأسلوب Anki (صناديق Leitner) تعرض ما تُنسى.
- **تعلّم تكيّفي**: صعوبة الأنشطة تتبدل حسب الأداء في الوقت الفعلي.
- **التلعيب**: نقاط XP، شارات، سلاسل أيام، إحصائيات.
- **الغمر التدريجي**: تتراجع نسبة الترجمة العربية من 20% (A1) إلى 90% (B2).
- **التغذية الراجعة الفورية**: تصحيح لحظي مع شرح سبب الخطأ.

### تقنياً
- تصميم متجاوب (هاتف/حاسوب) بألوان مستوحاة من العلم الفرنسي + خطوط تدعم العربية والفرنسية.
- لوحة تحكم (تقدم، نقاط ضعف، وقت، مفردات SRS).
- نظام حسابات (تسجيل/دخول) وحفظ التقدم محلياً.
- قاموس مصغّر مدمج مع بحث عربي/فرنسي.
- تصدير تقرير تقدم أسبوعي/شهري.
- شريك محادثة (Chatbot) يحاكي مواقف حقيقية ويصحح الأخطاء أثناء الحوار (مع ملاحظة حول دمج Claude API).

## 🚀 التشغيل

```bash
npm install
npm run dev       # بيئة التطوير (مع إعادة تحميل فوري)
npm run build     # بناء نسخة الإنتاج إلى dist/
npm run preview   # معاينة نسخة الإنتاج
```

## 🗂️ بنية المشروع

```
src/
  data/          محتوى المستويات (A1, A2, B1, B2) + القاموس + الفهرس
  lib/           التخزين، SRS، الصوت (TTS/STT)، التغذية الراجعة، حساب التقدم
  context/       سياق التطبيق (المصادقة، الإشعارات)
  components/    مزوّد الأنشطة، اختبار المستوى/الوحدة
  pages/         الصفحات: الرئيسية، المستويات، الدرس، لوحة التحكم، SRS، القاموس، المحادثة، التقرير
```

## 🧠 ملاحظة حول دمج Claude API (اختياري متقدم)

شريك المحادثة الحالي يعمل عبر منطق سيناريوهات مبنيّ في `src/pages/Chat.jsx` (بدون مفتاح API).
لدمج نموذج Claude حقيقي، استبدل دالة `respond()` بطلب `POST` إلى واجهة Anthropic `/v1/messages`
مع تمرير سجلّ الحوار وتعليمات التصحيح بالفرنسية. تُخزَّن المفاتيح على الخادم فقط (Var/Env)، لا في المتصفح.

## ⚠️ ملاحظة عن حفظ البيانات

نسخة تجريبية: تُخزَّن بيانات الحسابات والتقدم محلياً في `localStorage` للمتصفح.
لا تُرسَل كلمات مرور حساسة. لبيئة إنتاج حقيقية، استبدل طبقة التخزين في `src/lib/storage.js` بقاعدة بيانات (Firebase / Supabase / REST API).
